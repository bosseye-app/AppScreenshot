# App Store스크린샷 제작 도구 개인정보 처리방침

최종 업데이트: 2026년 10월 5일

## 개요

App Store스크린샷 제작 도구 는 완전히 오프라인으로 동작하는 macOS용 스크린샷 편집 앱입니다. 개인정보를 수집·전송·공유하지 않습니다.

## 수집하는 정보가 없습니다

- 계정 가입도 로그인도 필요하지 않습니다.
- 서버가 없으며, 앱은 우리나 제3자에게 어떤 데이터도 보내지 않습니다.
- 분석·통계·광고 SDK가 포함되어 있지 않습니다.
- 네트워크 접근 권한을 요청하지 않습니다.

## 파일 접근

- 앱은 시스템 파일 선택 창에서 사용자가 직접 고른 이미지와 프로젝트 파일만 읽을 수 있습니다.
- 선택한 파일의 경로(보안 범위 북마크)는 다음 실행 시 자동 복원을 위해 사용자의 Mac에만 저장됩니다.
- 이 기록은 앱 안에서 언제든지 삭제할 수 있습니다.

## 데이터 저장 위치

- 디자인 설정 값은 이 앱의 macOS 환경설정(로컬)에 저장됩니다.
- 가져온 이미지는 메모리에서만 사용되고, 내보낸 이미지는 사용자가 선택한 폴더에 저장됩니다.
- 앱을 삭제하면 이러한 로컬 데이터도 함께 삭제됩니다.

## 인앱 구매

- 구매와 구독은 Apple이 App Store를 통해 처리합니다.
- 저희는 결제 정보를 받거나 저장하지 않습니다. 앱은 기능 해제를 위해 구매 여부만 시스템에 확인합니다.

## 아동 개인정보

- 앱은 어떤 데이터도 수집하지 않으며, 아동을 대상으로 한 콘텐츠도 포함하지 않습니다.

## 방침 변경

- 본 방침이 변경되면 이 문서와 위의 최종 업데이트 날짜를 갱신합니다.

## 문의

- 궁금한 점이 있으면 App Store 제품 페이지의 'App 지원'을 통해 연락해 주세요.
